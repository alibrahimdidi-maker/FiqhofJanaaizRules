# SHA0719 — Fiqh of Janaza Rules (فقه أحكام الجنائز)

GitHub Pages slide site. Module-code gate: **SHA0719**.

## Folder
- `index.html` — gate + 14 weeks (15 slides each, diagrams + mind maps)
- `weeks/SHA0719_weekNN_slides.html` — each week as a separate code set (standalone page)
- `fonts/Faruma.ttf` — Dhivehi font (embedded with @font-face)

## Show / hide weeks
Bottom of `index.html`:  `var LAST_VISIBLE_WEEK = 14;`  (e.g. 5 = weeks 1-5 only)

## Screen / font
Responsive (phone, tablet, desktop). Floating **A- / A+** buttons change slide text size.

## Week plan (per module outline SHA0719)
1 Importance of the subject, death concepts · 2 Dying person & first acts · 3 Bathing · 4 Kafan · 5 Janazah prayer
6 Carrying & burial · 7 After burial, martyrs, siqt, limbs, suicide · 8 Following janazah, ta'ziya, grave visiting
9 Deeds that benefit the deceased · 10 Modern medical issues (post-mortem, clinical death, euthanasia, organ donation)
11-13 Practical training at the cemetery (x3) · 14 Revision
